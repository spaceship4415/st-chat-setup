# 채팅방 입장 관리 사용 가이드

[English](README.md)

실리태번에서 캐릭터를 누르면 **바로 채팅방에 들어가지 않고, 입장창이 먼저 뜨게** 해 주는 확장입니다.
입장창에서 **누구로(페르소나)**, **어느 채팅으로(새 채팅 / 기존 채팅)**, **어떤 로어북으로** 들어갈지 고른 뒤 입장해요.
휴대폰에서 쓰기 편하게 만들었습니다.

---

## 1. 설치하기

1. 실리태번 위쪽의 **확장 프로그램**(퍼즐 모양 아이콘)을 누릅니다.
2. **Install Extension**을 누릅니다.
3. 이 저장소 주소를 붙여 넣고 **Install**을 누릅니다.

   ```text
   https://github.com/spaceship4415/st-chat-setup
   ```

설치가 끝나면 캐릭터 목록에서 캐릭터를 눌러 보세요. 입장창이 뜹니다.

---

## 2. 입장창 한눈에 보기

```text
┌ 채팅방 입장 ─────────────────────────┐
│ 캐릭터   Seraphina          [✎ 수정] │
│ 페르소나 [Alice ▼]                    │
│ 채팅     ● 새 채팅 [Seraphina - Alice - …] │
│          ○ 기존 채팅 (3)              │
│ ▼ 로어북                              │
│   캐릭터   Eldoria                    │
│   페르소나 없음                       │
│   채팅     없음                       │
│               [입장] [취소]           │
└───────────────────────────────────────┘
```

위에서부터 **누구와 → 누구로 → 어느 채팅에서 → (필요하면) 로어북** 순서로 고르면 됩니다.
**취소**, 창 바깥 누르기, **ESC** 중 아무거나 하면 아무것도 바뀌지 않고 닫혀요.

---

## 3. 페르소나

이 채팅에서 **내가 누구로 대화할지** 고릅니다.

### 새 채팅일 때
- 처음엔 **실리태번이 원래 골랐을 페르소나**가 선택돼 있어요.
  (캐릭터에 연결된 페르소나 → 기본 페르소나 → 지금 쓰던 페르소나 순서)
- 칸에 보이는 페르소나가 **이 채팅에 고정**됩니다. 다음에 이 채팅을 열면 다른 페르소나를 쓰고 있었어도 자동으로 그 페르소나로 바뀌어요.
- **자동 (SillyTavern 규칙 따름)**을 고르면 고정하지 않고, 채팅을 열 때마다 실리태번이 정합니다.

### 기존 채팅일 때
- 처음엔 **기존 설정 유지 (Alice)**처럼 그 채팅에 지금 고정된 페르소나가 보여요.
- 다른 페르소나를 고르면 입장할 때 그 채팅의 페르소나가 바뀝니다.
- **고정 해제**를 고르면 고정을 풀어요.

> 💡 아래에서 채팅을 바꾸면 페르소나 칸도 그 채팅 기준으로 다시 맞춰집니다.
> 기존 채팅의 페르소나를 바꾸고 싶다면 **채팅을 먼저 고른 다음** 페르소나를 바꾸세요.

---

## 4. 채팅

### 새 채팅
- 이름이 `캐릭터 - 페르소나 - 2026-10-03 03h08` 형태로 미리 채워져 있어요. 원하는 이름으로 고쳐도 됩니다. 날짜 부분의 모양은 설정에서 바꿀 수 있어요.
  같은 이름이 이미 있으면 ` (2)`, ` (3)` …이 자동으로 붙어요.
- 대체 인사말이 있는 캐릭터는 **시작 인사말**을 고를 수 있어요. 앞부분이 미리 보이고, 고른 인사말로 채팅이 시작됩니다.
  (다른 인사말도 그대로 스와이프로 남아 있어요)
- 페르소나를 바꾸면 이름의 페르소나 부분도 따라 바뀌어요. (이름을 직접 고친 뒤에는 그대로 둡니다)
- 이름 칸에서 키보드의 **이동/Enter**를 누르면 바로 입장합니다. 한글 조합 중의 Enter는 무시하니 안심하세요.
- 같은 이름의 채팅이 이미 있으면 알려 주고 입장하지 않아요. 기존 채팅을 **덮어쓰는 일은 없습니다.**
- 파일 이름에 쓸 수 없는 글자(`/ : ? *` 등)는 자동으로 빠집니다.

### 기존 채팅
- **최근 대화 순**으로 보여요. 이름, 날짜, 메시지 수, 마지막 메시지 일부가 나옵니다.
  미리보기에서는 `*`, `**`, HTML 태그 같은 꾸밈 기호를 빼고 글자만 보여 줘요. (시작 인사말 미리보기도 같아요)
- **마지막으로 연 채팅**에는 표시가 붙고, 처음부터 선택돼 있어요.
- 줄 아무 데나 누르면 선택됩니다.
- 채팅이 4개 이상이면 위에 **검색칸과 정렬**이 나와요.
  - 검색은 채팅 이름과 마지막 메시지에서 찾아요. 고른 채팅이 검색 결과에서 빠지면 보이는 첫 채팅이 선택됩니다.
  - 정렬: 최근 순 / 오래된 순 / 이름 순 / 메시지 많은 순. 마지막으로 고른 정렬을 기억해요.
- 각 줄 오른쪽의 ✏️ 로 **이름 바꾸기**, 🗑️ 로 **삭제**를 할 수 있어요.
  - 같은 이름이 이미 있으면 바꾸지 않아요.
  - 삭제는 한 번 더 확인을 받고, **되돌릴 수 없어요.**
  - 지금 열려 있는 채팅은 여기서 삭제할 수 없어요. (이름 바꾸기는 돼요)

## 5. 로어북

자주 바꾸는 항목이 아니라서 **접혀 있고**, 지금 값만 세 줄로 보여 줍니다. ▼ 를 누르면 펼쳐져요.

| 로어북 | 어디에 붙나 | 바꾸면 |
| --- | --- | --- |
| **캐릭터 로어북** | 캐릭터 | 이 캐릭터의 **모든 채팅**에 적용 |
| **페르소나 로어북** | 페르소나 | 이 페르소나를 쓰는 **모든 채팅**에 적용 |
| **채팅 로어북** | 이 채팅 | **이 채팅만** |

칸 이름 옆에 적용 범위가 표시돼요. 캐릭터·페르소나 로어북은 다른 채팅에도 영향을 주기 때문에,
바꾸고 입장할 때 **"공유 설정을 바꿀까요?"** 확인 창이 한 번 뜹니다. 취소하면 아무것도 안 바뀌어요.

### 추가 로어북이 뭔가요?
캐릭터에 로어북을 **여러 개** 붙이는 기능이에요. 캐릭터 로어북 아래 **추가 로어북**을 펼치면 체크해서 고를 수 있습니다.

| | 기본 로어북 | 추가 로어북 |
| --- | --- | --- |
| 개수 | 1개 | 여러 개 |
| 저장 위치 | 캐릭터 카드 안 | 내 실리태번 설정에만 |
| 카드를 공유하면 | 같이 따라감 | 따라가지 않음 |

예) 기본 로어북은 세계관(Eldoria), 추가 로어북엔 내가 만든 사이드 설정을 붙여 두면 둘 다 함께 켜져요.

### 새 로어북 만들기
각 로어북 목록 맨 아래의 **＋ 새 로어북 만들기…**(추가 로어북은 목록 아래 버튼)를 누르면 이름을 묻고 빈 로어북을 만들어 줍니다.
만든 로어북은 모든 로어북 칸에 바로 추가되고, 누른 칸에서는 바로 선택돼요.
같은 이름이 이미 있으면 만들지 않습니다. (기존 로어북을 덮어쓰지 않아요)

> ⚠️ **캐릭터 카드에 로어북이 내장된 캐릭터**의 캐릭터 로어북을 **없음**으로 바꾸면,
> 실리태번이 **카드에 내장된 로어북도 함께 지웁니다.** 되돌릴 수 없어서, 이 경우엔 확인 설정을 꺼 두어도 항상 한 번 더 묻습니다.

## 6. 캐릭터 수정

입장창의 **✎ 수정**을 누르면 **빠른 수정** 창이 뜹니다. **채팅을 열지 않고** 캐릭터를 고칠 수 있어요.
(설정의 **수정 버튼**을 **기본 수정**으로 바꾸면 빠른 수정 없이 바로 실리태번 편집 화면이 열립니다. **둘 다**로 두면 [수정] 옆에 [ST 수정] 버튼이 함께 나와서 한 번에 갈 수 있어요.)

- 고칠 수 있는 것: 설명, 성격 요약, 시나리오, 첫 메시지, 대체 인사말, 대화 예시, 메인 프롬프트 덮어쓰기, 기록 후 지침, 제작자 노트
- 칸 제목 오른쪽의 **⤢ 버튼**을 누르면 그 칸을 **화면 가득 크게 열어서** 쓸 수 있어요(대체 인사말도 각각). 크게 연 창에서 쓴 내용은 바로 원래 칸에 들어갑니다.
- **저장**이나 **뒤로**를 누르면 입장창으로 돌아와요. 고친 걸 저장하지 않고 나가려 하면 한 번 물어봅니다.
- 이름·아바타·태그 같은 나머지 항목은 **ST 전체 수정 열기**로 실리태번 편집 화면에서 고쳐요.
  - 다른 캐릭터라면 그 캐릭터의 마지막 채팅이 함께 열립니다. (실리태번 편집 화면이 지금 캐릭터 기준이라서요)
  - 지금 대화 중인 캐릭터라면 채팅은 그대로 두고 편집 화면만 열려요.

빠른 수정과 실리태번 편집 화면은 서로 맞춰집니다. 어느 쪽에서 고쳐도 다른 쪽에 보여요.

## 7. 캐릭터 복제

캐릭터 목록의 각 캐릭터 오른쪽에 있는 **복제 버튼**(겹친 네모 모양)을 누르면, 묻지 않고 바로 복제돼요.
편집 화면에 들어갈 필요가 없어요.

- 복제본 이름은 **`이름 (2)`**처럼 붙어요. 이미 있으면 `(3)`, `(4)`로 올라가요. `Seraphina (2)`를 복제해도 `(2) (2)`가 아니라 `Seraphina (3)`이 됩니다.
- 카드 내용(설명, 인사말, 내장 로어북, 정규식 등)과 태그는 그대로 따라와요.
- 실리태번 기본 복제로는 안 따라오는 **추가 로어북, 작가 노트의 캐릭터 노트, 정규식 실행 허용, 페르소나 고정**도 함께 옮겨요.
- **기본 로어북은 같은 로어북을 함께 써요.** 복사본이 새로 생기는 게 아니라서, 로어북 내용을 고치면 원본과 복제본 둘 다에 반영돼요. (추가 로어북도 마찬가지)
- **채팅 기록은 따라오지 않아요.** 복제본은 채팅 없이 시작해요.
- 격자 보기와 일괄 편집 모드에서는 버튼이 숨겨져요.
- 버튼이 필요 없으면 설정의 **캐릭터 목록에 복제 버튼 표시**를 끄면 돼요.

## 8. 설정

**확장 프로그램 → 채팅방 입장 관리**를 펼치면 됩니다.

| 설정 | 하는 일 |
| --- | --- |
| 캐릭터 선택 시 채팅방 입장 UI 사용 | 끄면 예전처럼 캐릭터를 누르는 즉시 들어갑니다 |
| 입장창을 열 때 고를 채팅 | **새 채팅**(기본) / **기존 채팅**(마지막으로 연 채팅) / **지난번 선택 기억**. 하던 채팅을 주로 이어 하면 '기존 채팅'으로 두면 [입장] 한 번이면 돼요. 채팅이 없는 캐릭터는 새 채팅이 선택됩니다 |
| 새 채팅 이름의 날짜 | **SillyTavern 기본**(`2026-10-03@03h08m20s063ms`) / **날짜**(`2026-10-03`) / **날짜 + 시:분**(`2026-10-03 03h08`, 기본) / **날짜 + 시:분:초**(`2026-10-03 03h08m20s`). 채팅 이름은 파일 이름이라 `:`를 쓸 수 없어 `03h08`처럼 표시돼요. 같은 이름이 있으면 ` (2)`가 붙습니다 |
| Shift/Ctrl/Alt + 클릭 시 바로 입장 | PC에서 키를 누른 채 클릭하면 입장창 없이 바로 들어가요 |
| 캐릭터 목록에 복제 버튼 표시 | 캐릭터 목록의 각 캐릭터에 복제 버튼을 보여 줘요(기본 켜짐). [7. 캐릭터 복제](#7-캐릭터-복제) 참고 |
| 현재 캐릭터를 다시 클릭할 때도 입장 UI 표시 | 지금 대화 중인 캐릭터를 눌러도 입장창이 떠요(기본 켜짐). 끄면 실리태번처럼 편집 화면이 열립니다 |
| 수정 버튼 | **간편 수정**(기본): 채팅을 열지 않는 빠른 수정 창 / **기본 수정**: 바로 실리태번 편집 화면(다른 캐릭터면 그 캐릭터의 마지막 채팅도 함께 열려요) / **둘 다**: 두 버튼을 모두 보여 줘요. 휴대폰 작은 배치에서는 이름이 가려지지 않게 [✏️] [↗ ST]로 줄여 보여요 |
| 입장창 이미지 | **작게**(기본) 또는 **크게 (나란히)**. 크게를 고르면 캐릭터와 페르소나 이미지를 원본 화질로 나란히 크게 보여 주고, 그 아래에 [수정]과 페르소나 선택이 놓여요 |
| 페르소나/캐릭터 로어북을 바꿀 때 확인 | 다른 채팅에도 영향을 주는 변경 전에 확인 창을 띄워요 |

## 9. 자주 묻는 질문

**Q. 캐릭터를 눌렀는데 입장창이 안 떠요.**
설정에서 **캐릭터 선택 시 채팅방 입장 UI 사용**이 켜져 있는지 보세요.
캐릭터 목록의 **일괄 편집 모드**에서는 누르기가 '선택'이라 입장창이 뜨지 않아요.

**Q. 첫 화면의 '최근 채팅'을 누르면 입장창 없이 들어가요.**
정상이에요. 이 확장은 **캐릭터 목록에서 캐릭터를 누를 때**만 입장창을 띄웁니다.
최근 채팅, 슬래시 명령(`/go` 등), 그룹 채팅은 실리태번 원래 방식 그대로예요.

**Q. 입장 버튼을 눌렀는데 창이 안 닫혀요.**
들어가는 동안엔 **"입장 중…"**이 표시되고 창이 잠깐 남아 있어요.
실패하면 창 아래에 이유가 나오고, 그대로 다시 **입장**을 누르면 됩니다.
실패하면서 생긴 빈 채팅 파일은 자동으로 지워요.

**Q. 채팅 이름을 바꾸고 싶어요.**
이미 만든 채팅의 이름은 실리태번의 채팅 관리에서 바꿔 주세요. 입장창은 새 채팅 이름만 정합니다.

**Q. 다른 기기에서도 설정이 그대로인가요?**
